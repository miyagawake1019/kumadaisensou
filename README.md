# くま大戦争 (Bear Great War)

## ゲームの遊び方 (How to Play)
このゲームはタワーディフェンス型のゲームです。
お金（¥）を貯めて、味方のクマたちを召喚し、敵の拠点を破壊しましょう！

### ユニット (Units)
1.  **こぐま (Little Bear)** - ¥100
    *   基本ユニット。コストが低い。
2.  **柱グマ (Pillar Bear)** - ¥300
    *   少し強い。盾役として優秀？
3.  **おオグマ (Big Bear)** - ¥500
    *   攻撃力が高い主力ユニット。
4.  **最大おおぐま (Max Bear)** - ¥1000
    *   最強のクマ。召喚して戦況をひっくり返そう。

### ルール (Rules)
*   時間経過で敵も出現します。
*   敵は時間が経つにつれて強くなります。
*   敵の拠点のHPを0にすると勝利です。
*   自分の拠点のHPが0になると敗北です。

## 実行方法 (How to Run)
`index.html` をブラウザで開いてください。
